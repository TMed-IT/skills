# Skills

独自の工夫や判断基準をまとめたskillのコレクションです。既存のskillで足りない部分を補い、必要なものを組み合わせて使います。

| Skill | 用途 |
| --- | --- |
| [ui-design-rules](ui-design-rules/SKILL.md) | 待機表示、操作、整列、アクセシビリティの実装と確認 |
| [japanese-ui-writing](japanese-ui-writing/SKILL.md) | 日本語UI文言の語彙、句点、改行、補足文の整理と確認 |

## 使い方

各ディレクトリの `SKILL.md` が入口です。必要なskillだけをエージェントのskillディレクトリへ配置するか、シンボリックリンクを作成します。Codexでは `~/.agents/skills/<skill名>` から各ディレクトリを参照できます。

## 追加・更新の方針

- 既存skillや公式ドキュメントの転載、移動、言い換えだけのものは置かない。実際の利用で得た独自の判断基準や手順など、補完する価値があるものを置く。

- 1つの用途を1つのディレクトリにまとめ、名前と適用条件を `SKILL.md` のfrontmatterに書く。
- 本文には判断に必要な指針を置き、詳しい手順や例は必要に応じて読む `references/` へ分ける。
- 特定のサイトのブランド、パス、認証設定、修正履歴は利用側のプロジェクトに残す。
- 他のskillの導入や全skillの一括読み込みを前提にしない。関連skillがある場合は、その作業で必要になる箇所だけ案内する。
- 各skillの適用条件と必須仕様を守る。必須仕様は、対象の操作や状態があるすべての製品に適用する。
